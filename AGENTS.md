# Project Context: Apex Liberta Personal Website

This repository is used for hosting the personal website of **Apex Liberta** via GitHub Pages.

## Purpose

The site serves as a central hub to showcase:

- **Software Projects**: Technical work and coding endeavors.
- **Novels**: Creative writing and literary works.
- **Personal Works**: Miscellaneous creative or personal interests.

## Project Structure

- `site/src/`: Contains the source files for the website (e.g., `index.html`, `index.css`). This is where most development occurs. Currently contains a minimalist landing page.
- `.github/workflows/`: Contains GitHub Actions workflows, specifically for deploying the site to GitHub Pages.
- `assets/`: Stores static assets such as fonts and images used across the site.

## Development Guidelines

- Maintain a minimalist and clean aesthetic.
- Ensure responsiveness for both mobile and desktop devices.
- Support light and dark modes using CSS variables and media queries.
